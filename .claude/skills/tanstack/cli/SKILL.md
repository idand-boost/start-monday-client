# TanStack CLI

## Rules

| File                 | When to read                                    |
| -------------------- | ----------------------------------------------- |
| `cli-create.md`      | Scaffolding a new TanStack Start or Router app  |
| `cli-add.md`         | Adding add-ons to an existing project           |
| `cli-search-docs.md` | Searching or fetching TanStack docs in terminal |

## Navigation

- Scaffolding a new project → read `rules/cli-create.md`
- Adding integrations later → read `rules/cli-add.md`
- Looking up an API or pattern → read `rules/cli-search-docs.md`
